Le **web scraping** aussi appelé **harvesting** (en français le "**moissonnage"**) est une technoque d'extraction automatisée de données en ligne à l'aide d'un programme ou d'un script. C'est la principale forme du *data mining*.

Ce projet sera consacré au scraping du site web d'**Amazon,** le plus grand géant mondial du commerce en ligne et du cloud computing. Servant de place de marché incontournable pour des millions de venders et d'acheteurs.

---

**OBJECTIF DU PROJET**

Ce projet a pour objectif de nous apprendre la récupération des données sur le web, la gestion de ces données par le néttoyage et le stockage dans des fichiers ou des bases de données pour plus tard les exploiter.
